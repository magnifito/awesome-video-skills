## mgvideo

Usage: mgvideo [options] [command]

Magnifito Super Video CLI - maintained video production toolkit

Options:
  -V, --version                             output the version number
  -h, --help                                display help for command

Commands:
  doctor                                    Check the selected worker, pinned tools, fonts, and required
                                            provider configuration
  catalog                                   Show capabilities, source provenance, observed versions, and
                                            approved versions
  init [options] <project>                  Create a private job workspace with versioned brief, brand, asset,
                                            and toolkit locks
  plan <project>                            Produce the claims-linked scene plan and select its renderer and
                                            timing authority
  preview [options] <project>               Start interactive local HTTP preview server with live timeline
                                            scrubber
  render [options] <project>                Execute a frozen render request and write a separately identified
                                            run result
  validate [options] [run]                  Check files, facts, timing, layout evidence, and export
                                            specifications; record unresolved review items
  check [options] [project]                 Check on-screen text from the project files without rendering a
                                            video (clipped, safe zone, size, reading time, overlap, contrast)
  review                                    Blind review loop: frame sheets for a reviewer who sees no code,
                                            and a pass decided in code from its rounds
  ledger                                    Generation ledger (<project>/generations.json): reuse a generated
                                            asset instead of paying for it twice
  package [options] <run>                   Verify version-bound approvals and rights, then assemble the
                                            permitted client delivery
  cost [options] <run>                      Audit production compute, storage, and agent cost for a render run
  batch [options] <catalog>                 Render a multi-SKU commerce batch with retry manifests and
                                            per-product status
  upstream                                  Track and propose upstream changes
  report [options] <project>                Generate an executive delivery report and compliance audit in
                                            Markdown and JSON
  diff <targetA> <targetB>                  Compare two render outputs or frames for visual drift and quality
                                            degradation
  migrate <project>                         Upgrade project brief and brand specifications to current schema
                                            version
  inspect <file>                            Audit media file technical specifications, codecs, loudness, and
                                            color space
  recipe [id]                               Explore available shot recipes and motion parameters
  storyboard [options] <project>            Generate visual storyboard cards and interactive review contact
                                            sheet
  clean [options] <project>                 Purge temporary render caches, interim files, and older runs
  thumbnail [options] <target>              Extract a promotional poster frame or thumbnail from a video or
                                            project
  reframe [options] <video>                 Reframe master video to target aspect ratio (16:9, 9:16, 1:1, 4:5)
  grade [options] <video>                   Apply curated cinematic color grade preset (cool-tech,
                                            warm-vibrant, high-contrast, rec709-neutral, matte-film)
  waveform [options] <media>                Generate high-resolution audio waveform visualizer PNG
  notify [options] <project>                Print a webhook notification payload for CI/CD integrations (does
                                            not send it)
  bundle [options] <deliveryDir>            Bundle deliverables and checksums into immutable .tar.gz
                                            production package
  dashboard                                 Display an executive status dashboard of worker health, workflows,
                                            and budgets
  verify-bundle [options] <bundle>          Verify SHA256 checksums, the HMAC signature (MGVIDEO_SIGNING_KEY)
                                            and the approved review record inside a production bundle
  proxy [options] <video>                   Generate lightweight 540p / 720p editing proxy for fast playback
  watermark [options] <video>               Burn semi-transparent security banner or embargo notice into
                                            review video
  speed [options] <video>                   Adjust playback speed of a video with pitch-preserved audio
  safezone [options] <video>                Burn mobile platform safe area bounding guide onto video for QA
                                            analysis
  concat [options] <clips...>               Concatenate multiple video clips, normalizing resolution and audio
                                            sample rates
  lower-third [options] <video>             Burn broadcast lower-third title badge onto video clip
  brand                                     Check brand profiles (brand.json)
  chapters [options] <project>              Generate YouTube chapters, WebVTT cues, and QuickTime markers from
                                            scene plan
  loop [options] <video>                    Create seamless ping-pong loop (forward + reverse) for social
                                            reels and backgrounds
  freeze [options] <video>                  Hold start or final frame of a video using tpad cloning
  blur-bg [options] <video>                 Place 9:16 vertical video onto 16:9 landscape canvas over an
                                            aesthetic blurred background
  gate <project>                            Run comprehensive automated pre-delivery quality gate and
                                            compliance audit
  framerate [options] <video>               Convert video to target broadcast or social framerate (24, 25, 30,
                                            60 fps)
  deinterlace [options] <video>             Normalize interlaced footage to clean progressive scan frames via
                                            yadif
  eq [options] <audio>                      Apply audio equalization and vocal frequency sweetening
  montage [options] <images...>             Stitch storyboard styleframes into an animated review animatic
                                            video
  mask [options] <video>                    Redact sensitive on-screen client credentials, API keys, or PII
  channel-map [options] <audio>             Remap audio channel layouts (mono-to-stereo, stereo-to-mono,
                                            left-only-to-stereo)
  optimize [options] <video>                Constrain video bitrate to meet file size limits (e.g. Discord
                                            25MB, WhatsApp 16MB)
  merkle <dir>                              Compute cryptographic Merkle tree root hash of deliverable
                                            directory
  resample [options] <audio>                Resample audio to broadcast standards (48000 Hz) or custom rate
  reverse [options] <video>                 Reverse video and audio playback for rewind transitions or
                                            boomerang loops
  matte [options] <video>                   Overlay cinematic letterbox or pillarbox matte bars (2.39:1,
                                            1.85:1, 4:3)
  sfx [options] <target>                    Synthesize a procedural effect (sfx <whoosh|thud|pop|chime>), or
                                            run the measured sound pass on a video (sfx <video> --cues
                                            cues.json --out dir)
  sanitize [options] <media>                Strip sensitive camera metadata, geolocation, author tags, and
                                            local paths
  chromakey [options] <video>               Key out green or blue screen background and composite over
                                            background plate
  title [options] <video>                   Burn high-resolution typographic title card into video frames
  noise-gate [options] <audio>              Mute background noise floor and ambient hum during speech pauses
  smart-crop [options] <video>              Reframe video into target aspect ratio with focal point bias
                                            (9:16, 1:1, 4:5, 16:9)
  pan [options] <audio>                     Adjust stereo pan position (-1.0 left to +1.0 right) and stereo
                                            width
  glitch [options] <video>                  Apply stylized chromatic aberration and digital glitch artifacts
  multicam [options] <videos...>            Tile multiple synchronized camera angles into a split-screen
                                            layout (side-by-side, top-bottom, quad-2x2)
  compress-audio [options] <audio>          Apply dynamics compression with loudness-matched makeup gain
                                            (keeps input loudness)
  pip [options] <mainVideo> <overlayVideo>  Insert picture-in-picture overlay in screen corner (bottom_right,
                                            top_right, bottom_left, top_left)
  vignette [options] <video>                Apply subtle cinematic lens edge darkening
  declick [options] <audio>                 Eliminate mouth clicks, lip-smacks, and electrical pops from
                                            dialogue
  setup                                     Install optional managed toolchains into the user cache (never
                                            into the repo)
  transcribe [options] <media>              Recognise speech locally (faster-whisper) and write a Transcript
                                            with word times
  edit                                      Footage edits that write an Edit Decision List (edl.json)
  separate [options] <video>                Separate a subject from the background with SAM 2.1 from click
                                            points; writes masks, a green preview and an alpha cut-out
  broll                                     Motion B-roll on footage: caption words, plan check, clip render
                                            (full = opaque MP4, panel = transparent ProRes 4444) and compose
  help [command]                            display help for command

## mgvideo broll

ProRes 4444) and compose

  -h, --help                      display help for command

## mgvideo chromakey

Usage: mgvideo chromakey [options] <video>

Key out green or blue screen background and composite over background plate

Options:
  -k, --key <color>         Chroma key color (default: 0x00FF00) (default: "0x00FF00")
  -s, --similarity <value>  Share of the key-to-neutral chroma distance keyed fully transparent (0.01 to 1.0)
                            (default: "0.65")
  --blend <value>           Soft-edge width above the similarity, same scale (0 to 1) (default: "0.15")
  --no-despill              Keep green/blue spill on the foreground instead of neutralising it
  -b, --bg <path>           Optional background image or video path
  -o, --out <path>          Custom output video path
  -h, --help                display help for command
